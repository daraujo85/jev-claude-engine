# Smart File Explorer (JEV)

Encontre os arquivos exatos relevantes para a sua tarefa sem desperdiçar tokens abrindo arquivos desnecessários.

## Uso
```bash
node /Users/diegoaraujo/Documents/projects/jev-claude-engine/skills/jev-explore/explore.js "<termo ou conceito que deseja encontrar>"
```
Ou invoque `/jev-explore <termo>` diretamente.
